# Surface 3 — LaTeX

Native TikZ macros for borders, frames, and page decoration in LaTeX
documents. Implemented separately from the R/xspline surface (not a
shared asset) so borders stay vector-scalable and tile correctly at any
page size, but sharing the same visual language: heritable color drift,
a smooth-to-faceted blend, and the corner-tick motif.

Scoped to page chrome — covers, section breaks, margins, frames — never
inside a figure or table itself.
