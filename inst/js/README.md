# Surface 1 — interactive

Self-contained HTML/JS/CSS delighter snippets (canvas-based, no external
dependencies, fonts inlined as data URIs) for Quarto HTML documents, Shiny
apps, and standalone pages. Species #1 (the organic mitosis specimen from
"A Part That Does Nothing") is the reference implementation this whole
package is named after — it lands here once ported in.

Each species is one self-contained file: copy-paste into an HTML doc, or
have an R helper drop it in via `htmltools::tags`.
